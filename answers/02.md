# Task 02 Answer

`./tools/recruit-info` 能运行，是因为 `./` 明确告诉 shell 脚本位置就在当前目录的 tools 文件夹里，shell 直接找到并执行。

直接输入 `recruit-info` 找不到，是因为 shell 只在 PATH 环境变量列出的目录中查找程序，tools/ 不在 PATH 里。

shell 输入 `ls` 时，会在 PATH 里依次查找名为 ls 的可执行文件，通常找到 /usr/bin/ls。要让 recruit-info 直接运行，可把它的目录加进 PATH，例如 export PATH="$PATH:$(pwd)/tools"。
